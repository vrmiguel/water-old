# water - คอมไพเลอร์รูปแบบข้อความ WebAssembly

> **[Read in English](README.md)** | **[Lire en français](README.fr.md)**

คอมไพเลอร์ที่เบาและมีประสิทธิภาพสำหรับรูปแบบข้อความ WebAssembly (WAT) เขียนด้วยภาษา Rust

## ภาพรวม

`water` คือพาร์เซอร์และคอมไพเลอร์ขนาดเล็กแต่มีประสิทธิภาพสำหรับรูปแบบข้อความของ WebAssembly ที่มนุษย์อ่านได้ โดยเป็นพื้นฐานสำหรับการพาร์สโมดูล WAT, คำสั่ง, การนำเข้า, ฟังก์ชัน และส่วนประกอบอื่น ๆ ของ WebAssembly

## คุณสมบัติ

- **พาร์สได้รวดเร็ว** - พาร์สคำสั่งและโมดูล WAT ได้อย่างมีประสิทธิภาพด้วย `nom`
- **พึ่งพาน้อย** - โค้ดเบาพร้อมเฉพาะไลบรารีที่จำเป็น
- **ปลอดภัยด้วยระบบชนิดข้อมูล** - ใช้ประโยชน์จากระบบชนิดข้อมูลของ Rust เพื่อแทน AST ได้อย่างปลอดภัย
- **ขยายได้** - สถาปัตยกรรมแบบโมดูลาร์ที่รองรับ emitter และ transformation แบบกำหนดเอง

## โครงสร้างโปรเจกต์

- `src/parser/` - ตรรกะการพาร์ส WAT สำหรับคำสั่ง ฟังก์ชัน การนำเข้า และโมดูล
- `src/emitter/` - ยูทิลิตีสำหรับการปล่อยโค้ดและการแปลง
- `src/ast.rs` - นิยาม Abstract Syntax Tree (AST)
- `src/leb128.rs` - การเข้ารหัสจำนวนเต็มความยาวแปรผัน LEB128
- `src/opcode.rs` - นิยาม opcode ของ WebAssembly

## เริ่มต้นใช้งาน

### ข้อกำหนดเบื้องต้น

- Rust 1.56 หรือใหม่กว่า

### การ build

```bash
cargo build --release
```

### การรัน

```bash
cargo run
```

## ไลบรารีที่ใช้

- **nom** (7.1.1) - ไลบรารี parser combinator
