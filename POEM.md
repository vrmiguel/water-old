# Water, WAT, and the Byte

I pour a module, ink-dark WAT,
in parentheses it starts to sing;
each name a ripple on the page,
each token, tight and glimmering.

The parser listens—patient, clean—
to whitespace, commas, borrowed air;
then shapes the stream to quiet nodes,
so meaning can be carried there.

At last the emitter seals the flow:
not poem now, but ready light—
a little river, crystal-binned,
that fits inside a single byte.
