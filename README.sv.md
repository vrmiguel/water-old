# water (WebAssembly TExt foRmat compiler)

`water` strävar efter att vara en liten och högpresterande WebAssembly Text Format-kompilator.

## Funktioner

- Högpresterande WebAssembly Text Format-kompilator
- Skriven i Rust för säkerhet och prestanda
- Designad för att vara liten och snabb

## Installation

```bash
cargo build --release
```

## Användning

```bash
./target/release/water input.wat
```
