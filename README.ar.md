# water - مترجم WebAssembly Text Format

> **الترجمات:** [English](README.md) | [Français](README.fr.md)

مترجم خفيف وعالي الأداء لتنسيق WebAssembly Text Format (WAT)، مكتوب بلغة Rust.

## نظرة عامة

`water` هو محلل ومترجم بسيط ولكنه فعال للتنسيق النصي المقروء للبشر الخاص بـ WebAssembly. يوفر أساسا لتحليل وحدات WAT والتعليمات والاستيرادات والدوال ومكونات WebAssembly الأخرى.

## الميزات

- **تحليل سريع** - تحليل فعال لتعليمات ووحدات WAT باستخدام `nom`
- **اعتماديات قليلة** - قاعدة شيفرة خفيفة لا تحتوي إلا على الاعتماديات الأساسية
- **أمان الأنواع** - يستفيد من نظام الأنواع في Rust لتمثيل AST بأمان
- **قابل للتوسعة** - معمارية معيارية تدعم مولدات الشيفرة والتحويلات المخصصة

## هيكل المشروع

- `src/parser/` - منطق تحليل WAT للتعليمات والدوال والاستيرادات والوحدات
- `src/emitter/` - أدوات توليد الشيفرة والتحويل
- `src/ast.rs` - تعريفات شجرة البنية المجردة (AST)
- `src/leb128.rs` - ترميز الأعداد الصحيحة متغيرة الطول LEB128
- `src/opcode.rs` - تعريفات رموز تشغيل WebAssembly

## البدء

### المتطلبات

- Rust 1.56 أو أحدث

### البناء

```bash
cargo build --release
```

### التشغيل

```bash
cargo run
```
