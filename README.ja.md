# water - WebAssembly テキスト形式コンパイラ

> **[英語版を読む](README.md)** | **[Lire en français](README.fr.md)**

Rust で書かれた、WebAssembly テキスト形式 (WAT) のための軽量かつ高性能なコンパイラです。

## 概要

`water` は、WebAssembly の人間が読める形式のテキストを処理する、最小限ながら効率的なパーサ兼コンパイラです。WAT のモジュール、命令、インポート、関数、その他の WebAssembly 構成要素を解析するための基盤を提供します。

## 特徴

- **高速な解析** - `nom` を利用した効率的な WAT 命令およびモジュールの解析
- **最小限の依存関係** - 必要不可欠なものだけに絞られた軽量なコードベース
- **型安全** - Rust の型システムを活かした安全な AST 表現
- **拡張性** - カスタムエミッタや変換処理に対応したモジュール式アーキテクチャ

## プロジェクト構成

- `src/parser/` - 命令、関数、インポート、モジュールの WAT 解析ロジック
- `src/emitter/` - コード生成および変換のためのユーティリティ
- `src/ast.rs` - 抽象構文木の定義
- `src/leb128.rs` - LEB128 可変長整数エンコーディング
- `src/opcode.rs` - WebAssembly オペコードの定義

## はじめに

### 前提条件

- Rust 1.56 以降

### ビルド

```bash
cargo build --release
```

### 実行

```bash
cargo run
```
