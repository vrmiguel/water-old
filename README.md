# water (WebAssembly TExt foRmat compiler)

`water` aims to be a tiny and performant WebAssembly Text Format compiler.

## A Poem About Water

In text we write what machines must do,
WebAssembly flowing, clean and true.
From WAT to binary, water flows free,
A compiler so small, yet mighty as the sea.

With nom it parses, instruction by line,
LEB128 encoding makes numbers align.
Rust keeps it swift, the AST takes its form,
From source to emission, a standardized norm.

Functions and imports dance through the code,
Each opcode precisely mapped down the road.
No bloat, no waste, just what we require,
Water—the compiler that takes us much higher.
