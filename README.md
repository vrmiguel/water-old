# water (WebAssembly TExt foRmat compiler)

`water` aims to be a tiny and performant WebAssembly Text Format compiler.

## A Poem about Water

```
From text to binary, flowing swift and lean,
Water compiles the code that can't be seen.
WAT source melts through parser's careful hand,
Building instructions that machines understand.

Tiny and performant, this compiler flows,
Through abstract syntax trees as understanding grows.
Each opcode crystallized in LEB128's stream,
WebAssembly bytecode—a developer's dream.

Rust-forged and steadfast, water finds its way,
Converting human-readable text to code that will play.
In the realm of WASM, where efficiency reigns,
Water's elegant compiler breaks no chains.

From module to function, from parse to emit,
Every byte optimized, precisely knit.
A flowing transformation, clear and bright,
Turning WAT into binaries of pure light.
```
