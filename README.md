# water (WebAssembly TExt foRmat compiler)

`water` aims to be a tiny and performant WebAssembly Text Format compiler.

## A Poem

```
From text to binary, swift as a stream,
Water flows through code, a compiler's dream.
Tiny and nimble, performant and bright,
Transforming WAT with elegant might.

Where WebAssembly's format takes its stand,
Water compiles with a steady hand.
No bloat, no waste, just pure translation,
A focused tool for code transformation.

Like water finds the path of least resistance,
This compiler works with swift persistence.
From human-readable text it flows,
To binary form that execution knows.
```
