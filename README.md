# water (WebAssembly TExt foRmat compiler)

`water` aims to be a tiny and performant WebAssembly Text Format compiler.

## A Poem

*In the flow of binary streams so deep,*
*Where instructions dance and memories keep,*
*Comes water, pure and swift and bright,*
*Transforming text to WebAssembly's might.*

*From WAT to WASM, the journey goes,*
*Through parser gates where syntax flows,*
*Tiny in size, yet powerful and fast,*
*Compiling dreams from first to last.*

*Like water finds its perfect way,*
*Through rocks and valleys, come what may,*
*This compiler brings your code to life,*
*Cutting through complexity like a knife.*

*So let it flow, this tool so grand,*
*WebAssembly at your command,*
*With water's grace, your modules thrive,*
*In the web, forever alive.*
