# water (WebAssembly TExt foRmat compiler)

`water` aims to be a tiny and performant WebAssembly Text Format compiler.

---

## A Poem

In streams of code where bytes flow free,
WebAssembly dances gracefully.
Through water's lens, the text transforms,
From human words to binary forms.

Compile with speed, compile with care,
A tiny tool beyond compare.
Where web and assembly meet as one,
The future's built, the work is done.
