# water (WebAssembly TExt foRmat compiler)

`water` aims to be a tiny and performant WebAssembly Text Format compiler.

## Poem

Small text becomes a river's code,
Through brackets, bytes, and brittle road.
We name the current, shape the stream,
Till modules wake from quiet dream.

From wat to wasm, clear and tight,
It runs where engines carry light.
So let this compiler, swift and true,
Turn written waves to work for you.
