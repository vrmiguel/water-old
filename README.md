# water (WebAssembly TExt foRmat compiler)

`water` aims to be a tiny and performant WebAssembly Text Format compiler.

## A Poem for water

*Like water flowing through the stream,*
*This compiler turns text to wasm's dream.*
*Tiny and swift, performant and clean,*
*The finest WebAssembly tool you've seen.*

*From source to binary, the transformation flows,*
*Through water's path, efficiency grows.*
*Text format parsed with elegant grace,*
*Compiling modules at lightning pace.*

*In the world of web, where speed is king,*
*water brings performance on its wing.*
*A compiler pure, both small and bright,*
*Turning WebAssembly text to might.*
