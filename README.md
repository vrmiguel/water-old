# water (WebAssembly TExt foRmat compiler)

`water` aims to be a tiny and performant WebAssembly Text Format compiler.

## A Poem for Water

```
    In the depths where code flows clear,
    Water rises without fear,
    Parsing text in formats grand,
    WAT compiled with steady hand.

    From S-expressions typed with care,
    To binary floating through the air,
    With nom's combinators, swift and strong,
    Water compiles the whole thing long.

    Small strings optimized, memory wise,
    LEB128 encoded, no surprise,
    Instructions flow like currents true,
    WebAssembly, born anew.

    Tiny in size, but mighty still,
    Bending format to its will,
    Rust-built bridges, fast and lean,
    Water: where code and bytes convene.
```
