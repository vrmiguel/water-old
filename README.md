# water (WebAssembly TExt foRmat compiler)

`water` aims to be a tiny and performant WebAssembly Text Format compiler.

## Ode to Water

Silent runes of wasm drift like rain,
Pooling into bytes that calm the plain;
Streams of tokens carve a lucid trail,
Trees take form where parser winds prevail.
From droplets forged in LEB128 light,
Emerge instructions clear, compact, and bright.
