# water (WebAssembly TExt foRmat compiler)

`water` aims to be a tiny and performant WebAssembly Text Format compiler.

## Features

- Compiles WebAssembly Text Format to binary format
- Tiny and performant implementation
- Written in Rust using the `nom` parsing library
