# water (WebAssembly TExt foRmat compiler)

`water` aims to be a tiny and performant WebAssembly Text Format compiler.

## A Poem for Water

In streams of binary, water flows,
Through WebAssembly's text it goes,
Compiling code both fast and light,
Transforming formats, pure and bright.

From human words to machine tongue,
A bridge where both worlds are strung,
Tiny, swift, and ever true,
Water makes the old seem new.
