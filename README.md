# water (WebAssembly TExt foRmat compiler)

`water` aims to be a tiny and performant WebAssembly Text Format compiler.

## A Poem

In streams of code, where logic flows,
Through text format, the water goes.
Compiling symbols, line by line,
WebAssembly's dance, both small and fine.

Tiny and swift, performant too,
Transforming text to binary true.
Like water flowing, clear and bright,
The compiler works through day and night.
